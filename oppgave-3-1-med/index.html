Slik ser det ut i kode

Med CUDA skriver du én funksjon, og hver tråd på GPU-en kjører den for sitt eget element. Her legges to lister sammen, ett tall per tråd.

__global__ void add(int n, float *a, float *b, float *c) {
  int i = blockIdx.x * blockDim.x + threadIdx.x;
  if (i < n) c[i] = a[i] + b[i];
}
